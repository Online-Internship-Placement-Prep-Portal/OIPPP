## Member 4 design notes

- The ER diagram uses the separate `Result` model rather than the old diagram's `Attempt.score`, and names the shared `Profile` model rather than the older display name `StudentProfile`.
- The aptitude sequence diagram shows the server timeout sweep, the canonical Result and acknowledged saves. It no longer shows a Python analytics component writing a readiness snapshot.
- TST-5's ambiguous 0–30 second window is resolved by the hard cutoff in row 10; `attempt-timeout.job.js` submits overdue attempts on the server.
- The [ADR-2](../adr/ADR-2-server-side-test-timer.md) record explains the server-owned timer.
- See the [decision register](aptitude-analytics-quality.md#decision-register-for-implementation-hand-off) and the [diagram guide](diagrams/README.md).
